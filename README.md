# ssomcp

Unofficial MCP server for preparing Thai Social Security Office monthly
contribution filings (สปส.1-10).

The project is designed as a review-first TypeScript/Node.js workflow. It
prepares a human-review spreadsheet and fixed-width TIS-620 upload file, then
uses browser automation only after explicit user confirmation. The final
submission remains under human control.

See [PROJECT.md](PROJECT.md) for the design, safety boundaries, implementation
plan, and source layout.

> This project is unofficial and is not affiliated with the Thai Social
> Security Office.
